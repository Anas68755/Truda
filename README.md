# الأصيلة العشرة · 10 Originals

**A bilingual hub of ten original, hand-crafted browser games and creative apps — five games and five apps, all playable offline in one page.**

[Open the hub](https://anas68755.github.io/Truda/)

## 🎮 The five games

| Game | What you do |
|---|---|
| [Khayal: Shadow Play](https://anas68755.github.io/Truda/games/khayal.html) — خيال الظل | Compose hand-shadow silhouettes behind the lamp, then perform the tale live. |
| [Hive Maestro](https://anas68755.github.io/Truda/games/hive-maestro.html) — مايسترو الخلية | Dance the waggle on the beat to send the swarm to nectar. |
| [ʿAbq: Scent Ledger](https://anas68755.github.io/Truda/games/abq.html) — عَبق | Decode a client's memory and blend its perfume before the evidence evaporates. |
| [The Three Winds](https://anas68755.github.io/Truda/games/three-winds.html) — الرياح الثلاث | Sculpt dunes with the wind itself to carry your caravan through. |
| [Netwright](https://anas68755.github.io/Truda/games/netwright.html) — ناسج الشباك | Knot your net to the blueprint's spec, then cast it among the shoals. |

## 🧰 The five apps

| App | What it does |
|---|---|
| [Mizwala: Sundial Studio](https://anas68755.github.io/Truda/apps/mizwala.html) — مِزْوَلة | Design a real sundial for any latitude and print its template. |
| [Windbells Studio](https://anas68755.github.io/Truda/apps/windbells.html) — أجراس الريح | Tune wind bells with real physics and let the breeze perform them. |
| [Mirrorseal](https://anas68755.github.io/Truda/apps/mirrorseal.html) — الخَتم المعكوس | Engrave mirrored art that reads true when pressed into wax. |
| [Darb al-Ḥarf](https://anas68755.github.io/Truda/apps/darb-al-harf.html) — ضَرب الحَرف | Sketch a letter skeleton, cut it with a broad nib, print a specimen. |
| [Shamsa](https://anas68755.github.io/Truda/apps/shamsa.html) — شَمْسَة | Compass & Rosette Studio. |

## ✨ Highlights

- 🇸🇦 **Fully bilingual** — every title, tagline and interface is available in Arabic and English with instant switching.
- 📴 **Offline-first** — no accounts, no servers, no installation; everything runs in the browser.
- 📱 **Responsive** — works on phones and desktops.
- 🎨 **Original themes** — crafts, trades and natural phenomena (shadows, bees, scents, wind, knots, sundials, seals, type, compasses).

## 🛠️ Tech

- HTML5 / CSS3 / vanilla JavaScript — no build step, no dependencies.
- Hosted free on GitHub Pages.

## 🚀 Local use

Clone or download this repository and open `index.html` in any modern browser — no installation or server required.
